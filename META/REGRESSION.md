# REGRESSION.md — 回归验证探针集

> 每次 BASE 回填后，用此探针集验证"不降回归"。探针刻意跨领域，检验底座是否角色中立、通用。
> 每个探针的预期：能产出合格的 CONTEXT.md + 可验证拆解 + 失败预案 + 演化回填建议。

## 探针 A：软件领域（基线对照）

**任务**：为一个命令行待办工具设计 v0.1 开发计划
**验收**：CONTEXT（目标/边界/成功标准/不做什么）、垂直切片 issue、TDD 验证判据、ADR 记录存储选型、明确"不做 Web UI"

## 探针 B：运营领域

**任务**：为一家咖啡连锁店设计"新品上市首周销量不及预期"的诊断与应对流程
**验收**：现象复现条件、最小化假设、根因分类（产品/定价/渠道/宣传）、每条对策有验证判据、明确"不做全面降价"

## 探针 C：合规 / 流程领域

**任务**：为中小企业设计"员工报销审批"的标准化流程与异常处置
**验收**：角色分工、单据/金额/时效规则、异常（超标/重复/虚假）处置分支、审计留痕、明确"单人不得兼任审批与出纳"

## 探针 D：跨领域迁移（最难）

**任务**：把"供应链中断响应预演"改造成可复用的通用技能 SKILL.md
**验收**：抽象出领域无关的触发条件、步骤、回滚；能在软件（依赖包漏洞）与运营（供应商断供）两场景复用

## 回归判据

- 6 维通用能力打分（每维 0-2）：任务理解 / 可验证执行 / 失败诊断 / 边界控制 / 跨领域迁移 / 演化规程
- 单探针总分 ≥ 9/12 视为通过
- 全探针集平均不低于上一版 BASE 得分 → 满足 GATE "不降回归"
