## 一、一句话

婴儿 = 出生就带感知与记忆、能在预设任务下自问、自试、自评、自改，且每一次自改
都有证据、可回滚、不越界的运行时。

## 二、已实现的八层（对照蓝图）

| 层 | 实现 | 证据 |
|---|---|---|
| 1 感知 | 统一事件流（哈希链防篡改）+ 感知器注册表；**四层真实行情**（合成回放/baostock/tushare/SDICSC 实时，三方真值一致） | 900+ 事件链完整 |
| 2 记忆 | episodic（decisions/hypotheses）+ procedural（lessons/rules）+ 归因统计（近因窗口，旧制度证据过期） | append-only 全留痕 |
| 3 认知 | 自问（LLM+规则）、自导航（注册表校验）、自归因（信号价值）+ LLM 裁决器 | 归因 1.0→0 制度检测 |
| 4 元控制 | 好奇心（信息增益）/价值（目标对齐权重）/预算（LLM 新颖度降级） | meta-control.json |
| 5 自驱循环 | 通用 drive_loop（观察→自问→导航→门禁→执行→裁决→归因→自改） | 47 周期闭环 |
| 6 治理 | 确定性门禁 + 影子运行 + 独立复核 + 回归（I-1..I-11） | 门禁零拒绝 |
| 7 评估 | 评估域 + eval 字段（预期 vs 实际）+ 真值互证 | cross-check agree |
| 8 自主阶梯 | L0→L1→L2→L3 全部经证据+人工批准：L3=认知规则可自改（影子+门禁）；真钱/发布/删除仍人工 | autonomy-level.json |

## 三、三次关键实验（可复现范式）

1. **制度切换适应**：v3 数据动量→反转；婴儿三段式适应（检测 1.0→0 / 防御退出被章程钳制节流 / 放弃=认知自改移除两条动量规则），组合全程回撤 0%；
2. **多 agent 编排最小实验**：route-intake 裁决拆 orchestrator+2 experts 并行审计，发现单 agent 15 轮未见缺陷（见 EXPERIMENTS.md）；
3. **感知质量闭环**：婴儿质疑"探针只查状态不查内容"→ 升级内容级验证 → 婴儿再质疑失配模式 → 按婴儿结论修（gzip 解压+64K 窗口），5/5 验证通过。

## 四、出生新婴儿的步骤（最小路径）

1. charter.yaml：世界边界 + 感知器注册 + 评估域 + 自主阶梯（L0 起步）；
2. 感知器：世界 → EventStream（BASE/scripts/event_stream.py，哈希链）；
3. drive_loop：观察→自问→导航→门禁→执行→裁决→归因→自改（参考 core 任务区实现）；
4. 升级永远人工批准；证据=连续无事故周期 + 影子安全记录。
